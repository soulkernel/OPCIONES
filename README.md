# Opciones de arriendo WWF

Sitio web interactivo para explorar y comparar cuatro opciones de arriendo en
la isla Santa Cruz, Galápagos.

## Contenido

- Informe descriptivo responsive con los datos de cada opción.
- Galerías navegables por propiedad y por ambiente.
- Mapas interactivos y enlaces para abrir rutas en Google Maps.
- Ficha completa con características, precio y datos de contacto.
- Tabla comparativa sin calificaciones ni recomendaciones.

La página no clasifica las opciones ni propone una alternativa. Presenta la
información contenida en los archivos suministrados para que cada persona haga
su propia evaluación.

## Publicación directa en GitHub Pages

La raíz del repositorio contiene `index.html`. No requiere compilación:

1. Sube todo el contenido del repositorio a GitHub.
2. En **Settings → Pages**, selecciona **Deploy from a branch**.
3. Elige la rama `main` y la carpeta `/ (root)`.

También puedes abrir `index.html` directamente en un navegador para revisar la
página. El mapa requiere conexión a Internet.

No requiere Node.js, instalación de dependencias ni proceso de compilación.
Las fotografías optimizadas se encuentran en `public/properties`.
